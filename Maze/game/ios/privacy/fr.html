Politique de confidentialité

Minik Maze

Apps By Bros publie Minik Maze pour iPhone et iPad (com.appsbybros.minik.maze). Mise à jour : 16 octobre 2026. Questions ou demandes de suppression : appsbybros.dev@gmail.com.

La progression, les réglages, les aventures inachevées et les adaptations de difficulté restent sur votre appareil. Aucun vrai nom, courriel, contact, microphone, caméra ou position précise n’est nécessaire. Désinstaller efface les données locales. Aucun SDK d’analyse d’usage n’est inclus.

Le catalogue Minik de l’espace adulte est inclus dans l’app ; l’afficher n’envoie aucune requête. Les liens externes nécessitent l’accès adulte. Ce site n’utilise ni suivi, ni analyse d’audience, ni cookies publicitaires. L’hébergeur peut conserver des journaux d’accès ordinaires.

Cette version ne contient aucun SDK publicitaire, aucune publicité ni promotion automatique. Les 12 premiers niveaux sont gratuits. Un achat définitif via l’App Store débloque la suite, sans abonnement. Réinitialiser la progression locale ne supprime pas cet achat. Les liens facultatifs vers les autres applications sont dans l’espace adulte.

L’App Store d’Apple gère les achats. L’app reçoit le produit et le statut de propriété pour restaurer les achats, pas les données de carte bancaire. Nous ne vendons pas les records et ne demandons pas de vrais noms aux enfants. Contactez-nous pour l’accès ou la suppression. Consultez aussi la politique de confidentialité d’Apple.
